# Dragon's Fury

Dragon's Fury is a Minecraft mod designed to transform the game by introducing new dimensions, unique mobs, and custom crafting mechanics. This mod aims to make Minecraft more interesting by adding fresh content and gameplay elements. It is built for Minecraft 1.21.1 using the NeoForge mod loader.

## Install

1. Download the mod file from the GitHub releases page.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. Launch Minecraft with the mod installed.
2. Explore the new custom dimension to discover unique mobs and resources.
3. Use the custom crafting mechanics to create new items and tools.
4. Engage with the new gameplay mechanics to enhance your Minecraft experience.
